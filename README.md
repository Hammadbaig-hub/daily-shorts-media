# daily-shorts-media

Media and tools for the **Bright Life** YouTube channel (@Bright-Life-m4).

- `tools/scripts/make_short.py` — renders a 1080x1920 animated-text Short with voiceover
- `tools/scripts/voice.py` — free offline narration (Kokoro TTS)
- `tools/scripts/plan_today.py` — picks today's language/theme from `history.json`
- `videos/` — rendered Shorts (only the newest 20 are kept)
- `history.json` — log of every published Short
